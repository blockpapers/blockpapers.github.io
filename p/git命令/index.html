Git 常用指令整理（分类版）

一、仓库初始化与配置

1. 初始化仓库 

1

git init

2. 克隆远程仓库 

1

git clone <url>

3. 配置用户信息 

1
2

git config --global user.name "Your Name"
git config --global user.email "you@example.com"

4. 查看配置 

1

git config --list

二、基本操作（增删改查）

1. 查看状态 

1

git status

2. 添加文件到暂存区 

1
2

git add <file>
git add .

3. 提交到本地仓库 

1

git commit -m "message"

4. 查看提交历史 

1
2

git log
git log --oneline

5. 查看差异 

1
2

git diff
git diff --cached

三、分支管理

1. 查看分支 

1

git branch

2. 创建分支 

1

git branch <branch-name>

3. 切换分支 

1

git checkout <branch-name>

或

1

git switch <branch-name>

4. 创建并切换 

1

git checkout -b <branch-name>

5. 删除分支 

1

git branch -d <branch-name>

四、远程仓库操作

1. 查看远程仓库 

1

git remote -v

2. 添加远程仓库 

1

git remote add origin <url>

3. 推送代码 

1

git push origin <branch>

4. 拉取代码 

1

git pull origin <branch>

5. 获取更新（不合并） 

1

git fetch

五、撤销与回退

1. 撤销工作区修改 

1

git checkout -- <file>

2. 取消暂存 

1

git reset HEAD <file>

3. 回退版本 

1

git reset --hard <commit-id>

4. 软回退 

1

git reset --soft <commit-id>

六、合并与变基

1. 合并分支 

1

git merge <branch>

2. 变基 

1

git rebase <branch>

七、标签管理

1. 创建标签 

1

git tag <tag-name>

2. 查看标签 

1

git tag

3. 推送标签 

1

git push origin <tag-name>

八、储藏（stash）

1. 保存当前修改 

1

git stash

2. 查看stash列表 

1

git stash list

3. 恢复stash 

1

git stash pop

九、日志与查看

1. 图形化日志 

1

git log --graph --oneline --decorate

2. 查看某次提交 

1

git show <commit-id>

十、删除与清理

1. 删除文件并提交 

1

git rm <file>

2. 清理未跟踪文件 

1

git clean -f

十一、常用组合操作

1. 一步提交 

1

git commit -am "message"

2. 拉取并变基 

1

git pull --rebase

十二、进阶（建议掌握）

1. 修改最后一次提交 

1

git commit --amend

2. 交互式变基 

1

git rebase -i HEAD~n

3. 查看文件历史 

1

git blame <file>

🔁 流程说明

  1. 在 工作区 修改代码
  2. 使用 git add 加入 暂存区
  3. 使用 git commit 提交到 本地仓库
  4. 使用 git push 上传到 远程仓库
  5. 使用 git pull 从远程更新到本地

总结

  • 工作区 → 暂存区：git add
  • 暂存区 → 本地仓库：git commit
  • 本地仓库 → 远程仓库：git push
  • 远程仓库 → 本地：git pull / git fetch
