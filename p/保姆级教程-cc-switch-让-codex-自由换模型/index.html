保姆级教程 | CC Switch 让 Codex 自由换模型

2026-06-20

Codex 现在热度很高，用的人不少，毕竟封号没像另外一家频繁，但对于重度用户来说，额度和成本依然是绕不开的问题。

之前配置接入第三方模型也不方便，现在好了，第三方工具 CC Switch v3.16.0 更新后，已经可以很方便的把第三方模型接入 Codex。

CC Switch 是一款免费开源的跨平台桌面工具，它能够在本地接管 Codex 等 AI 编程助手的请求，并将请求转发到你指定的 API 提供商，实现模型自由切换。

通过 CC Switch，你可以让 Codex 直接使用 DeepSeek、Qwen、智谱 GLM 等第三方大模型作为后端服务，在保留 Codex 使用体验的同时，大幅降低使用成本，并获得更多模型选择。

接下来我们基于 CC Switch v3.16.0，演示如何为 Codex 配置 DeepSeek 作为后端模型，其他兼容模型的配置方式也基本类似。

工作原理

CC Switch 会在本机启动一个轻量级代理服务。

当 Codex 发起请求时：

1

Codex → CC Switch → DeepSeek/Qwen/GLM → CC Switch → Codex

整个转发过程完全透明，对于 Codex 来说，它仍然认为自己正在访问 OpenAI 官方接口，而实际上，请求已经被 CC Switch 转发到了你指定的第三方模型服务。

这样就实现了：

  • 保持原有 Codex 使用体验
  • 自由切换模型提供商
  • 降低 API 使用成本
  • 避免频繁修改配置文件

前置条件

开始之前，请确认已准备好以下环境：

条件 说明
Codex 已安装 下载并安装 Codex
DeepSeek API Key 在 DeepSeek 开放平台注册获取
操作系统 Windows 10+、macOS 12+、主流 Linux 发行版
CC Switch 建议使用 v3.16.0 或更高版本

第一步：安装 CC Switch

安装包下载地址为 GitHub Releases，根据你的操作系统选择对应的安装方式。

macOS

macOS 版本已通过公证，可直接使用 Homebrew 安装：

1

brew install cc-switch

Windows

从 GitHub Releases 下载 .msi 安装包，双击运行即可。

Linux 

1

sudo dpkg -i CC-Switch-*.deb

其他发行版安装方式：

发行版 推荐格式 安装方式
Ubuntu / Debian / Linux Mint .deb sudo dpkg -i CC-Switch-*.deb
Fedora / RHEL / CentOS .rpm sudo rpm -i CC-Switch-*.rpm
openSUSE .rpm sudo zypper install ./CC-Switch-*.rpm
Arch Linux / Manjaro .AppImage 添加执行权限后直接运行
其他发行版 .AppImage chmod +x CC-Switch-*.AppImage && ./CC-Switch-*.AppImage

安装完成后启动 CC Switch，主界面会出现在桌面或系统托盘。

第二步：添加 DeepSeek 提供商

在 CC Switch 中添加 DeepSeek 作为 API 提供商：

  1. 打开 CC Switch，在顶部应用切换栏选择 Codex
  2. 点击左侧 Providers 区域的 + Add Provider
  3. 在预设列表中搜索 DeepSeek，选择对应的预设（v3.16.0 已内置 DeepSeek V4 flash 和 pro 两个版本）
  4. 在表单中填入你的 DeepSeek API Key，其余字段使用默认值即可
  5. 开启本地路由映射，点击 保存

第三步：开启路由

切换到 DeepSeek 后，系统会提示开启路由：

  1. 点击左上角的 设置 按钮
  2. 进入 路由设置 菜单
  3. 开启路由
  4. 选择 Codex

完成

重新打开 Codex，就可以看到 DeepSeek 的模型标志了。现在你的 Codex 已经通过 CC Switch 接入了 DeepSeek 模型，可以享受更低的使用成本和更多的模型选择。
